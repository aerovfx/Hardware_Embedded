# Hardware Embedded

Kho học liệu mở về thiết kế chip, IoT, robotics và các hệ thống nhúng, kèm website học tập được sinh tự động từ Markdown.

## Website khóa học

Website nằm trong [`course-site`](course-site/) và hỗ trợ:

- Đọc bài học từ các thư mục `lessons/week*.md`.
- Theo dõi tiến độ học tập.
- Khảo sát học viên.
- Đánh giá đồng đẳng và chấm điểm giáo viên.
- Xuất kết quả dưới dạng JSON.

```bash
cd course-site
npm run build
npm run serve
```
